Agent Inbox — это платформа API для предоставления ИИ-агентам собственных входящих ящиков, позволяющая им отправлять, получать и обрабатывать электронные письма. Это позволяет агентам иметь собственную идентичность и общаться через универсальный протокол электронной почты с сервисами, людьми и другими агентами.
