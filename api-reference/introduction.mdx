## Добро пожаловать

Есть два способа создания API документации: [OpenAPI](https://mintlify.com/docs/api-playground/openapi/setup) и [MDX компоненты](https://mintlify.com/docs/api-playground/mdx/configuration). Для этого примера мы используем следующую OpenAPI спецификацию.

## Аутентификация

Все API endpoints защищены с использованием Bearer токенов, которые берутся из файла спецификации.

```json
"security": [
  {
    "bearerAuth": []
  }
]
```
