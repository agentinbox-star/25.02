Найдите ответы на частые вопросы об AgentInbox, от основных концепций до лучших практик и безопасности.

<AccordionGroup>
  <Accordion title="Что такое AgentInbox?">
    AgentInbox — это платформа электронной почты, ориентированная на API и разработанная специально для создания ИИ агентов, которые могут общаться по электронной почте. Хотя традиционные API электронной почты предназначены для отправки односторонних уведомлений, AgentInbox создан для двусторонних разговоров, что облегчает создание агентов, которые могут читать, понимать и отвечать на письма в цепи, как это делал бы человек.
  </Accordion>
  <Accordion title="Чем AgentInbox отличается от услуг типа SendGrid или Mailgun?">
    Ключевое отличие — это наш фокус на **агентов для разговоров**. Такие услуги, как SendGrid, отлично подходят для трансакционных писем (квитанции, сброс пароля) и маркетинговых кампаний. Они выполняются через GUI. Resend — это API, который отлично подходит для таких трансакционных писем тоже. НО AgentInbox создан для уникальных проблем, позволяющих агентам вести двусторонний разговор по электронной почте, с первоклассной поддержкой таких концепций, как `Threads`, `Inboxes` и `Attachments` для управления сложными, состояние-зависимыми разговорами по электронной почте.
  </Accordion>
  <Accordion title="Могу ли я использовать мой собственный пользовательский домен для отправки писем?">
    Да, конечно! Хотя вы можете начать работу сразу с входящим ящиком `@agentinbox.ru`, мы настоятельно рекомендуем настроить свой собственный домен для использования в производстве. Это улучшает доставляемость и гарантирует, что письма отправляются с вашего бренда. Вы можете найти полное руководство [здесь](/custom-domains).
  </Accordion>
  <Accordion title="Какой лучший способ обработки входящих писем?">
    Для производственных приложений **Webhooks — это рекомендуемый метод**. Они обеспечивают уведомления в реальном времени и намного эффективнее, чем постоянный опрос API на наличие новых сообщений. Вы можете узнать, как их настроить, в нашем [обзоре веб-хуков](/overview).
  </Accordion>
  <Accordion title="Как убедиться, что я не попаду в спам?">
    Доставляемость электронной почты — это сложная тема. Мы подробно рассматриваем это в нашем [руководстве по
    лучшим практикам доставляемости электронной почты](/email-deliverability).
  </Accordion>
  <Accordion title="У вас есть доступные SDK?">
    Да! Мы в настоящее время предлагаем официальные SDK для Node.js/TypeScript и Python, чтобы сделать интеграцию с AgentInbox максимально простой. Вы можете найти ссылки и информацию в нашей [справке API](/api-reference).
  </Accordion>
</AccordionGroup>
