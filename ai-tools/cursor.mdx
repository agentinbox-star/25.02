Настрой Cursor, чтобы помочь тебе писать и поддерживать документацию Mintlify.

## Требования

- Установленный редактор Cursor

## Настройка

<Steps>
<Step title="Открой свою папку документации в Cursor">
  Открой корень репозитория документации, где находится `docs.json`.
</Step>

<Step title="Установи Mintlify skill">
  В интегрированном терминале, выполни:

  ```bash
  npx skills add https://mintlify.com/docs
  ```

  Это дает Cursor справочник компонентов Mintlify, стандарты написания,
  и рекомендации по workflow.
</Step>

<Step title="Настрой инструкции проекта">
  Редактируй `AGENTS.md` в корне проекта, чтобы добавить специфичную для проекта терминологию,
  предпочтения стиля и границы контента.
</Step>

<Step title="Начни писать с Cursor">
  Открой файл и используй AI возможности Cursor для написания и редактирования документации.
</Step>
</Steps>
