Настрой AI ассистента Cascade из Windsurf, чтобы помочь тебе писать и поддерживать документацию Mintlify.

## Требования

- Установленный редактор Windsurf

## Настройка

<Steps>
<Step title="Открой свою папку документации в Windsurf">
  Открой корень репозитория документации, где находится `docs.json`.
</Step>

<Step title="Установи Mintlify skill">
  В интегрированном терминале, выполни:

  ```bash
  npx skills add https://mintlify.com/docs
  ```

  Это дает Windsurf справочник компонентов Mintlify, стандарты написания,
  и рекомендации по workflow.
</Step>

<Step title="Настрой инструкции проекта">
  Редактируй `AGENTS.md` в корне проекта, чтобы добавить специфичную для проекта терминологию,
  предпочтения стиля и границы контента.
</Step>

<Step title="Начни писать с Cascade">
  Открой файл и используй Cascade для написания и редактирования документации.
</Step>
</Steps>
