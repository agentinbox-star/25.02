Настрой Claude Code, чтобы помочь тебе писать и поддерживать документацию Mintlify.

## Требования

- Активная подписка Claude (Pro, Max, или API доступ)

## Настройка

<Steps>
<Step title="Установи Claude Code">
  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
</Step>

<Step title="Установи Mintlify skill">
  В папке документации, выполни:

  ```bash
  npx skills add https://mintlify.com/docs
  ```

  Это дает Claude Code справочник компонентов Mintlify, стандарты написания,
  и рекомендации по workflow.
</Step>

<Step title="Настрой инструкции проекта">
  Редактируй `AGENTS.md` в корне проекта, чтобы добавить специфичную для проекта терминологию,
  предпочтения стиля и границы контента.
</Step>

<Step title="Начни писать с Claude Code">
  ```bash
  claude
  ```
</Step>
</Steps>
