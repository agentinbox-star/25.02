Добавьте AgentInbox в ИИ-ассистентов по кодированию с официальным навыком

## Начало работы

AgentInbox предоставляет официальный навык, который можно установить на ИИ-ассистентов и агентов, поддерживающих формат AgentSkills. Это включает Moltbot, Claude Code, Cursor, Codex и другие совместимые инструменты.

## Установка

### Moltbot (скоро)

Установите навык, используя CLI Moltbot:

```bash
moltbot skills install agentinbox-to/agentinbox-skills/agentinbox
```

Или установите через ClawdHub:

```bash
clawdhub install agentinbox
```

### Claude Code (скоро)

Добавьте навык в конфигурацию Claude Code:

```bash
claude-code skills install agentinbox-to/agentinbox-skills/agentinbox
```

### Cursor (скоро)

Установите навык в Cursor:

```bash
cursor skills install agentinbox-to/agentinbox-skills/agentinbox
```

### Ручная установка (скоро)

Вы также можете вручную клонировать репозиторий навыка:

```bash
git clone https://github.com/agentinbox-to/agentinbox-skills.git ~/.skills/agentinbox
```

## Конфигурация

После установки настройте ваш API ключ AgentInbox. Метод варьируется в зависимости от платформы:

### Переменная окружения

Установите переменную окружения `AGENTINBOX_API_KEY`:

```bash
export AGENTINBOX_API_KEY="your-api-key-here"
```

### Конфигурация Moltbot

Добавьте API ключ в `~/.clawdbot/moltbot.json`:

```json
{
  "skills": {
    "entries": {
      "agentinbox": {
        "enabled": true,
        "env": {
          "AGENTINBOX_API_KEY": "your-api-key-here"
        }
      }
    }
  }
}
```

Получите ваш API ключ из консоли AgentInbox.

## Возможности

Официальный навык AgentInbox предоставляет комплексную функциональность электронной почты:

### Входящие ящики

Создавайте масштабируемые входящие ящики по требованию. Каждый входящий ящик имеет уникальный адрес электронной почты, который ваш ИИ-агент может использовать для отправки и получения писем.

### Сообщения

Отправляйте письма с простым текстом и HTML-содержимым для лучшей доставляемости. Навык автоматически обрабатывает правильное форматирование и заголовки.

### Цепи

Цепи группируют связанные сообщения в беседу, что облегчает отслеживание цепей писем и сохранение контекста в нескольких обменах.

### Вложения

Отправляйте и получайте вложения с кодированием Base64. Навык может извлекать вложения из сообщений или цепей.

### Черновики

Создавайте черновики для одобрения человеком перед отправкой. Это полезно, когда вы хотите проверить письма перед их отправкой.

### Поды

Мультитенантная изоляция для SaaS-платформ. Каждый клиент получает изолированные входящие ящики, идеальные для создания приложений с поддержкой электронной почты.

### События в реальном времени

Навык поддерживает как WebSockets (постоянное соединение, не требуется открытый URL), так и веб-хуки (HTTP-уведомления) для оповещений по электронной почте в реальном времени.

## Пример использования

После установки вы можете попросить вашего ИИ-ассистента выполнить задачи электронной почты:

- "Создай новый входящий ящик для моего проекта"
- "Отправь письмо на [john@example.com](mailto:john@example.com) о встрече завтра"
- "Проверь мой входящий ящик на новые письма"
- "Ответь на последнее письмо от Марии"
- "Создай черновой ответ на тикет поддержки"
