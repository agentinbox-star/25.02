Подключите AgentInbox к любому MCP-совместимому ИИ-клиенту

## Начало работы

Model Context Protocol (MCP) — это открытый стандарт, который позволяет ИИ-приложениям подключаться к внешним инструментам и источникам данных. AgentInbox предоставляет MCP-сервер, который позволяет любому MCP-совместимому клиенту взаимодействовать с API AgentInbox.

### Установка (скоро)

Чтобы начать работу с MCP-сервером AgentInbox, посетите **mcp.agentinbox**.to для получения инструкций по установке и деталей конфигурации.

## Возможности

MCP-сервер AgentInbox предоставляет инструменты для:

\* **Управление входящими ящиками:** создание, перечисление и удаление входящих ящиков

\* **Операции с сообщениями:** отправка, получение и ответ на письма

\* **Управление цепями:** доступ и управление цепями писем

\* **Вложения:** обработка вложений электронной почты

## Совместимые клиенты

MCP-сервер AgentInbox работает с любым MCP-совместимым клиентом, включая:

\* Claude Desktop

\* Cursor

\* Windsurf

\* Другие MCP-enabled ИИ-приложения
