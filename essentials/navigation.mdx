Навигационное меню - это список ссылок на каждой странице вебсайта.

Тебе нужно будет обновлять `docs.json` каждый раз, когда добавляешь новую страницу. Страницы не появляются автоматически.

## Синтаксис навигации

Наш синтаксис навигации рекурсивный, что позволяет создавать вложенные группы навигации. Не нужно включать `.mdx` в названия страниц.

<CodeGroup>

```json Обычная навигация
"navigation": {
  "tabs": [
    {
      "tab": "Документация",
      "groups": [
        {
          "group": "Начало работы",
          "pages": ["quickstart"]
        }
      ]
    }
  ]
}
```

```json Вложенная навигация
"navigation": {
  "tabs": [
    {
      "tab": "Документация",
      "groups": [
        {
          "group": "Начало работы",
          "pages": [
            "quickstart",
            {
              "group": "Вложенные справочные страницы",
              "pages": ["nested-reference-page"]
            }
          ]
        }
      ]
    }
  ]
}
```

</CodeGroup>

## Папки

Просто помести свои MDX файлы в папки и обнови пути в `docs.json`.

Например, чтобы создать страницу на `https://yoursite.com/your-folder/your-page`, тебе нужно создать папку `your-folder` с MDX файлом `your-page.mdx`.

<Warning>

Ты не можешь использовать `api` как имя папки, если не вложишь его внутри другой папки. Mintlify использует Next.js, который зарезервировал папку `api` верхнего уровня для внутренних вызовов сервера. Название папки как `api-reference` было бы приемлемым.

</Warning>

```json Навигация с папкой
"navigation": {
  "tabs": [
    {
      "tab": "Документация",
      "groups": [
        {
          "group": "Название группы",
          "pages": ["your-folder/your-page"]
        }
      ]
    }
  ]
}
```

## Скрытые страницы

MDX файлы, не включённые в `docs.json`, не будут отображаться в боковой панели, но доступны через поиск и прямыми ссылками.
