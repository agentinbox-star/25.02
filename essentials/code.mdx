## Встроенный код

Чтобы обозначить `слово` или `фразу` как код, заключи её в обратные кавычки (`).

## Блоки кода

Используй [огороженные блоки кода](https://www.markdownguide.org/extended-syntax/#fenced-code-blocks), заключив код в три обратные кавычки и указав язык программирования после них для подсветки синтаксиса. Опционально, ты можешь написать имя кода после языка программирования.

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Привет, мир!");
    }
}
```
