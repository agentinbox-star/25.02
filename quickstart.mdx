Это руководство проведет вас через установку AgentInbox, аутентификацию с вашим API ключом и создание вашего первого почтового ящика.

<Steps>
  <Step title="Получите доступ к консоли AgentInbox">
    Сначала вам нужно получить доступ к консоли AgentInbox для управления вашей учетной записью и API ключами. Щелкните ссылку ниже, чтобы начать.

    <Card icon="envelopes" href="https://console.agentmail.to" title="Открыть консоль AgentInbox">
      
    </Card>
    Если у вас еще нет учетной записи, вы можете зарегистрироваться прямо из консоли. После входа вы сможете управлять своими входящими ящиками, просматривать аналитику и создавать API ключи.
  </Step>
  <Step title="Создайте API ключ">
    Теперь, когда вы находитесь в консоли, вам нужно создать API ключ для аутентификации ваших запросов. Перейдите в раздел API Keys на панели управления консоли. <img src="file:95960235-a95c-4d4c-bb32-986b4629e984" alt="Снимок экрана создания API ключа" /> Щелкните "Create New API Key/Создать Новый API Ключ" и дайте ему описательное имя. После создания скопируйте API ключ и сохраните его в безопасном месте. Создайте файл `.env` в корневой папке вашего проекта и добавьте в него свой ключ. 

    Мы рекомендуем использовать переменные окружения для безопасного хранения ваших ключей.
  </Step>
  <Step title="Установите SDK или используйте API ключ">
    Установите SDK AgentInbox, используя предпочитаемый вами менеджер пакетов. Мы также будем использовать библиотеку для загрузки переменной окружения из файла `.env`.
  </Step>
  <Step title="Создайте входящий ящик и отправьте письмо">
    Теперь вы готовы сделать свой первый вызов API. Создайте новый файл (например, `quickstart.py` или `quickstart.ts`) и добавьте следующий код. Этот скрипт инициализирует клиент AgentInbox, создает новый входящий ящик и отправляет тестовое письмо.

    <Note>
      Предкпреждаем, что SDK может находится в статусе разработки или проверки со стороны нашей команды.
    </Note>
  </Step>
  <Step title="Запустите код">
    Выполните скрипт из вашего терминала.

    <CodeBlocks>
  ```bash title="Python"
        python quickstart.py
  ```

  ```bash title="TypeScript"
        npx ts-node quickstart.ts
  ```
</CodeBlocks>

    Вы должны увидеть детали вашего только что созданного входящего ящика, выведенные в консоль. Поздравляем, вы успешно создали свой первый входящий ящик AgentInbox!
  </Step>
</Steps>
