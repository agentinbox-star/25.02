## Запуск в три этапа

Запусти платформу агентов локально и проведи первую настройку.

### Шаг 1: Подготовь локальное окружение

<AccordionGroup>
  <Accordion icon="copy" title="Клонируй репозиторий локально">
    Во время регистрации вы создали GitHub репозиторий с содержимым документации. Ссылку на него можно найти в [панели управления](https://app.agentinbox.com).

    Чтобы скопировать репозиторий локально и иметь возможность вносить изменения, следуй инструкции [Клонирование репозитория](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) в документации GitHub.
  </Accordion>
  <Accordion icon="rectangle-terminal" title="Запусти сервер предпросмотра">
    1. Установи Mintlify CLI: `npm i -g mint`
    2. Перейди в директорию документации и выполни: `mint dev`
    3. Открой `http://localhost:3000` чтобы увидеть документацию в реальном времени!

    <Tip>Предпросмотр обновляется автоматически при изменении файлов.</Tip>
  </Accordion>
</AccordionGroup>

### Шаг 2: Развёртывание изменений

<AccordionGroup>
  <Accordion icon="github" title="Установи GitHub приложение">
    Установи Mintlify GitHub приложение из [панели управления](https://app.agentinbox.com/settings).

    Приложение автоматически развёртывает изменения на сайте документации, поэтому тебе не нужно управлять развёртыванием вручную.
</Accordion>
<Accordion icon="palette" title="Обнови название и цвета сайта">
    Давай обновим название и цветовую схему.

    1. Открой `docs.json` в редакторе.
    2. Измени поле `"name"` на название своего проекта.
    3. Обнови `"colors"` под свой корпоративный стиль.
    4. Сохрани и увидишь изменения мгновенно на `http://localhost:3000`.

    <Tip>Попробуй изменить основной цвет, чтобы увидеть результат!</Tip>
  </Accordion>
</AccordionGroup>

### Шаг 3: Публикация

<Accordion icon="rocket" title="Опубликуй документацию">
  1. Закоммитей и залей изменения.
  2. Документация будет обновлена и доступна буквально через несколько мгновений!
</Accordion>
