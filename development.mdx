<Info>
  **Требования**:
  - Node.js версия 19 или выше
  - Репозиторий документации с файлом `docs.json`
</Info>

Следуй этим шагам для установки и запуска Mintlify на твоей операционной системе.

<Steps>
<Step title="Установи Mintlify CLI">

```bash
npm i -g mint
```
</Step>

<Step title="Локальный предпросмотр">

Перейди в директорию с документацией, где находится файл `docs.json`, и выполни команду:

```bash
mint dev
```

Локальный предпросмотр документации будет доступен на `http://localhost:3000`.

</Step>
</Steps>

## Собственные порты

По умолчанию Mintlify использует порт 3000. Ты можешь изменить порт, используя флаг `--port`. Например, чтобы запустить Mintlify на порту 3333:

```bash
mint dev --port 3333
```

Если порт уже занят, система автоматически выберет следующий доступный:

```md
Port 3000 is already in use. Trying 3001 instead.
```

## Версии Mintlify

Каждый релиз CLI связан с конкретной версией Mintlify. Если твой локальный предпросмотр не совпадает с production версией, обнови CLI:

```bash
npm mint update
```

## Проверка ссылок

CLI может помочь с проверкой ссылок в документации. Чтобы найти неработающие ссылки, выполни:

```bash
mint broken-links
```

## Форматирование кода

Рекомендуем использовать расширения для IDE, чтобы распознавать и форматировать MDX. Если ты используешь VSCode, рассмотри [MDX VSCode extension](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx) для подсветки синтаксиса и [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) для форматирования.

## Решение проблем

<AccordionGroup>
  <Accordion title='Ошибка: Could not load the "sharp" module using the darwin-arm64 runtime'>

    Это может быть из-за устаревшей версии Node.js. Попробуй следующее:
    1. Удали установленную версию CLI: `npm remove -g mint`
    2. Обнови Node.js до версии 19 или выше.
    3. Переустанови CLI: `npm i -g mint`
  </Accordion>

  <Accordion title="Ошибка: Encountering an unknown error">

    Решение: Перейди в корень диска и удали папку `~/.mintlify`. Затем снова выполни `mint dev`.
  </Accordion>
</AccordionGroup>

Интересно, что изменилось в последней версии CLI? Посмотри [changelog](https://www.npmjs.com/package/mintlify?activeTab=versions).
