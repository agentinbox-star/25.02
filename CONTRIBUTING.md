# Внеси вклад в документацию

Спасибо за интерес к внесению вклада в нашу документацию! Это руководство поможет тебе начать.

## Как внести вклад

### Вариант 1: Редактирование напрямую на GitHub

1. Перейди на страницу, которую хочешь отредактировать
2. Нажми кнопку "Edit this file" (иконка карандаша)
3. Сделай изменения и подай pull request

### Вариант 2: Локальная разработка

1. Форк и клониши этот репозиторий
2. Установи Mintlify CLI: `npm i -g mint`
3. Создай ветку для своих изменений
4. Сделай изменения
5. Перейди в папку документации и выполни `mint dev`
6. Просмотри свои изменения на `http://localhost:3000`
7. Закоммитей свои изменения и подай pull request

Для более подробной информации о локальной разработке, смотри наш [гайд по разработке](development.mdx).

## Рекомендации по написанию

- **Используй активный залог**: "Выполни команду" вместо "Команда должна быть выполнена"
- **Обращайся к читателю напрямую**: Используй "ты" вместо "пользователь"
- **Держи предложения краткими**: Одна идея в предложении
- **Начни с цели**: Начинай инструкции с того, что хочет достичь пользователь
- **Используй консистентную терминологию**: Не чередуй синонимы для одного концепта
- **Включай примеры**: Показывай, не просто рассказывай
