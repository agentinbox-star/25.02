## Что такое AgentInbox?

AgentInbox — это платформа API для предоставления ИИ-агентам собственных входящих ящиков, позволяющая им отправлять, получать и обрабатывать электронные письма. Мы управляем инфраструктурой, чтобы вы могли сосредоточиться на создании почтовых агентов.

**Агенты электронной почты** могут:

- Вести беседы с пользователями в своих входящих ящиках
- Автоматизировать рабочие процессы на основе электронной почты для предприятий
- Аутентифицироваться с приложениями третьих сторон
- Действовать как полноценные пользователи в интернете

## Проблема с традиционной электронной почтой

Существующая инфраструктура электронной почты была создана для людей. Устаревшие поставщики, такие как Gmail и Outlook, имеют несколько ограничений для агентских случаев использования:

<CardGroup>
  <Card icon="code" title="Нет API для входящих ящиков">
    Устаревшие поставщики не поддерживают API для создания новых входящих ящиков по требованию.
  </Card>
  <Card icon="money-bill-1" title="Цена за входящий ящик">
    Они взимают ежемесячную подписку за входящий ящик (\$12/ящик/месяц !!), что дорого для агентов.
  </Card>
  <Card icon="light-emergency" title="Ограничительные лимиты">
    Они устанавливают ограничивающие лимиты скорости и отправки, не подходящие для автоматизации.
  </Card>
  <Card icon="comment-exclamation" title="Плохой DX">
    В целом, они предлагают плохой опыт разработчика для создания на основе электронной почты. Gmail API отстой!
  </Card>
</CardGroup>

## Решение

AgentInbox — это поставщик электронной почты, ориентированный на API и разработанный для агентов. Думайте о нем как о Gmail, но с:
